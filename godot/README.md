# ساحة القتال — لعبة FPS ثلاثية الأبعاد لـ Godot

مشروع Godot 4 قابل للعب، بواجهة عربية وتحكم للهاتف والكمبيوتر. يحتوي على ساحة ثلاثية الأبعاد، أعداء يلاحقون اللاعب، موجات متزايدة، صحة ونقاط وذخيرة وإعادة تلقيم وقفز.

## التشغيل

1. نزّل المستودع أو افتح هذا المجلد بعد تنزيله: `godot/`.
2. ثبّت Godot 4.3 أو أحدث.
3. من Godot اختَر **Import** ثم حدّد `godot/project.godot`.
4. اضغط **Run Project (F6)**.

## التحكم

- الهاتف: العصا الافتراضية أسفل اليسار للحركة، اسحب في الجهة اليمنى للتصويب، والأزرار لإطلاق النار/التلقيم/القفز.
- الكمبيوتر: WASD أو الأسهم للحركة، الفأرة للتصويب، زر الفأرة الأيسر للإطلاق، R للتلقيم، Space للقفز، Esc للإيقاف المؤقت.

المشروع يستخدم رسومات هندسية مدمجة ولا يحتاج ملفات أصول خارجية. إعدادات العرض تستخدم Compatibility renderer لملاءمة الأجهزة المحمولة. يمكن تصديره إلى Android أو Web من Godot بعد تثبيت Export Templates والمنصات اللازمة.
